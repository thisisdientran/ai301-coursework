# Rubric: is this reproduction package ready to post?

## Checks

| Check | Evidence | Pass condition | Weight |
|---|---|---|---|
| environment | the reproduction package has environment such as OS, browser, Runtime, package, library version, etc | at least 1 environment | Required |
|steps| Has steps such as 1, 2, 3 or -> --> in the instruction that stranger can reproduce the issue | Has at least 2 clear steps instruction to reproduce the problem | Required|
| behaviors | Show clear output without vague result such as clear error log, screenshots, expected or observer behaviors | Have at least 1 behavior | Required |
| Honesty | The reproduction package is closely related to the repo/issues | Relevant with the repo | Required |
| Comms | The repo is not against use AI in AI use policy | Pass if not see any mention related against in AI-contributing | Required |


## Verdict rule
- Accept only if ALL Required checks pass.
- Reject if ANY Required check fails.
- Preferred checks do not affect the verdict, they
rank accepted issues
- If unclear then count as fail
